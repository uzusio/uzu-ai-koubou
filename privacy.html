プライバシーポリシー

最終更新：2026 年 11 月 10 日

うずAI工房（以下「このアプリ」）は、天羽うずしお丸が作る Windows のアプリです。このページは、このアプリがどんな情報を、どこで、どう扱うかを説明します。

1. 私たちが受け取る情報

私たち（作者）は、このアプリを通じてあなたの情報を受け取りません。このアプリは私たちのサーバーと通信せず、使い方の統計や不具合の報告を自動で送ることもしません。

2. あなたの PC の中に置く情報

  • YouTube から読んだ情報：チャンネル・動画・再生リスト・分析の数字。あなたの PC の中（%APPDATA%\channel-steward）だけに置きます。YouTube の規約に従い、取ってから 30 日以内に取り直すか消します。
  • YouTube の許可（リフレッシュトークン）：Windows の資格情報マネージャーに置きます。画面・ログ・データベースには出しません。
  • あなたが入れた情報：目標・答えた質問・プラン・作業の記録。
  • 録画と書き出した動画：あなたが選んだフォルダにあります。録画は読むだけで、書き換えも削除もしません。

アンインストールのときに「アプリのデータを削除」を選ぶと、上の情報（書き出した動画を除く）を消します。

3. Google（YouTube）の情報の扱い

このアプリは、YouTube API サービスを使っています。このアプリで YouTube に接続すると、YouTube の利用規約に同意したことになります。Google が情報をどう扱うかは、Google のプライバシーポリシーをご覧ください。

このアプリに出した許可は、Google のセキュリティ設定のページからいつでも取り消せます。

このアプリは、Google の OAuth であなたの許可を得て、次の範囲で YouTube を使います。

  • youtube：動画・再生リストを読み、あなたが承認した変更（題名・概要欄・タグ・再生リスト・アップロード）を書き込むため。
  • yt-analytics.readonly：チャンネルの分析の数字を読み、提案に使うため。

Google API から受け取った情報の使用と、他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

うずAI工房's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. AI に渡す情報

あなたが AI の機能（マネージャーの提案・題名の案・場面選び・相談）を使うと、このアプリは、あなたの PC に入っている AI（Claude Code または Codex）に、必要なチャンネルの情報や文字起こしを渡します。AI はあなたの契約で動き、その情報は AI の提供元（Anthropic または OpenAI）に送られ、提供元の規約とプライバシーポリシーに従って扱われます。私たちはその情報を受け取りません。

AI に情報を渡すのは、あなたがアプリの中で使う AI を選び、AI の機能を使ったときだけです。このアプリも作者も、YouTube から読んだ情報を AI の学習に使いません。AI の提供元が会話を学習に使うかどうかは、あなたの契約と設定で決まります。気になる場合は、提供元の設定を確かめてください。

5. インターネットから取ってくるもの

初めて使うときなどに、次の配布元から部品を取ってきます。そのとき配布元には、あなたの IP アドレスなど、通常のダウンロードと同じ情報が伝わります。

  • Python（文字起こしの部品を動かすため）：GitHub
  • 文字起こしの部品：Python Package Index（PyPI）
  • 文字起こしのモデル：Hugging Face
  • 動画の道具（ffmpeg）：GitHub
