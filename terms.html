1. このアプリについて

うずAI工房（以下「このアプリ」）は、YouTube のチャンネルの運営を手伝う Windows 用のアプリです。体験版は無料で使えます。

2. YouTube の利用規約

このアプリは YouTube API サービスを使っています。このアプリで YouTube に接続して使うと、YouTube 利用規約に同意したことになります。

3. プライバシー

情報の扱いは、プライバシーポリシーに書いています。Google のプライバシーポリシーもあわせてご覧ください。

4. 自分の責任で使うこと

このアプリが YouTube に書き込む前には、必ず中身を画面に出し、あなたの承認を待ちます。承認した書き込みの結果は、あなたのチャンネルに反映されます。体験版は、動作を保証するものではありません。

5. 変更と終了

体験版の配布は、予告なく終えることがあります。この規約を改めたときは、このページの日付を更新します。
